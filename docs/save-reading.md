# 读取游戏存档

顶栏绿色「读取游戏存档」打开路径提示和选择窗口。默认目录是 `%USERPROFILE%\Saved Games\Order of the Sinking Star`；可点击「复制路径」后粘贴到系统目录选择器。选择存档目录后，挑选一个游戏档案的 `Status.sokoban_status`，点击「读取并标记」。只提供目录选择；多个档案不会合并。

目录选择明确使用 `showDirectoryPicker({mode: "read"})`，不请求 readwrite。不支持此 API 的浏览器使用只读目录文件选择器。代码只调用 getFile／arrayBuffer，没有写入、创建、删除或改名接口。

只在浏览器本地读取逐关 SOLVED 位。不会上传、修改或持续扫描存档，不读取迷雾、可达性、位置或世界历史。部分完成不计通关，地图外的 ID 忽略。不支持或不完整的文件会报错，已有标记不变。支持的 Status 版本为 5–33，依据 xPaw 的格式与版本字段顺序；引用版本与许可见 [来源说明](../third_party/xpaw/NOTICE.md)。

## 完成状态规则

- 手动标记仍在 `levels[id].completed`，存档通关快照单独存于 `saveProgress.solved`。
- 每次读取替换上一次存档快照，并清除上一次读取后的手动覆盖；存档中的已通关关卡优先生效，额外手动完成的关卡保持完成。
- 读取后手动取消一个存档已通关关卡，会保存手动 false 和 `saveProgress.overrides[id]=false`，统一显示未完成。再次读取会重新按存档标成完成。
- 浅红色「解绑存档」仅移除快照和覆盖，恢复手动标记结果，包括读取前和读取后做出的手动勾选／取消。
- 「重置所有更改」确认后清除所有手动、存档完成状态并解绑，同时恢复地图样式；名称、星星、多存档标记、备注保留。「恢复默认」只恢复全局样式和不透明度。

页面只显示完成／未完成，不显示来源类型。结果在本机保存，刷新后保留；不持久保存原文件或目录句柄，游戏进度更新后再次点「读取游戏存档」选择并读取。导出／导入名称与标注也包含手动记录、存档快照及覆盖；旧备份缺少 saveProgress 时不解绑，其 completed 字段按一次手动修改处理；显式 null 表示解绑。撤销历史包含存档变化，刷新后历史清空。

设置支持调整完成关卡不透明度（10%–100%，默认35%）；区域／关卡标签字号和默认位置各占同一行，区域标题、位置适应和关卡标签开关同一行。导航栏只保留网格与已完成开关。

浏览器对目录只读授权可能使用「读取和复制文件」一类措辞。读取本身允许把内容读入浏览器内存，无法另外禁止读取者复制；这不等于修改目录中文件的权限。本站仍只申请 read，未申请 readwrite。此提示与「复制路径」按钮的剪贴板操作不是同一权限。
