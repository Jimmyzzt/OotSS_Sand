## 使用

- 选择地图、分 P 和区域；侧栏序号定位关卡，时间戳打开攻略。选定分 P 后进入单区域，地图仍保留该 P 邻区的关卡标签。完整地图清除筛选。
- 单分 P 或单区域中点击侧栏铅笔，或双击区域标签进入微调。点击区域名称直接修改；侧栏支持批量改名。点击其他区域退出微调。
- 点击关卡标签或自定义文本，在侧栏编辑选中元素；编号可以拖动。Del 隐藏编号或删除文字，隐藏编号可点关卡后重新勾选显示。Ctrl+Z 撤销，Ctrl+Shift+Z 重做，仅保留本次页面最多 60 步。
- 微调中双击当前区域空白位置，点击 Tt 添加文本；文字可编辑、拖动，字号、颜色和描边在侧栏调整。新文字沿用本次页面最近使用的文字样式。
- 设置中调整标点、两类字号、位置和偏移，或切换标签显示与位置适应；位置适应只在单分 P / 单区域运行。取消“使用全局样式”可为区域单独设置。
- 关卡弹窗“关卡标记”内可标星星、多存档、备注。修改保存在本机，在设置中导出/导入名称与标注可备份、分享。
- 恢复默认只恢复全局样式；重置所有更改经确认后恢复各区域及元素样式，保留名称、文本内容/位置及关卡标记。
- 演示模式隐藏工具栏，左右箭头切换区域，Esc 退出；侧栏可拖动边缘调整宽度、收起。

## 性能依据

检查方式：同一内置浏览器，1280×720 视口，主世界地图区 913×635，初始适应范围后连续四次放大。旧版线上与新版本地分别检查 DOM；瓦片加载来源、缓存状态不同，因此不以此次检查推导网络速度或 FPS。

- 旧版：466 个关卡标点、466 个编号，约 5310 个 DOM 节点。
- 新版：32 个关卡标点、32 个编号，约 2630 个 DOM 节点。右侧全部 473 条时间记录仍在。
- 放大到细节时仅创建视野及 30% 预留范围的标点。平移复用已有标点，移出视野则释放；当前聚焦/打开弹窗的关卡保留。缩回概览恢复全部标点。侧栏定位和适应范围从完整数据取坐标。
- 避让测量与位置写入分批执行，避免每个区域交替读写布局。全部分 P 且未选区域时跳过避让。预览图仅在打开关卡弹窗时生成；未打开时 DOM 预览图数量为 0。
- 三地图内嵌 HTML 约 1.65 MB；本地 gzip 估算约 134 KB。Leaflet 与自有 JS 合计原始约 209 KB。gzip 是文件估算，不是网络实测传输量。
- 两轮放大到最大后返回完整地图，概览均恢复到 466 个标点、3918 个 DOM 节点（含旧有本机自定义文字），未见 DOM 累积。
- 编辑历史最多 60 个本次会话快照，不写入持久存储；数据与 DOM 检查未显示无界增长的缓存。浏览器工具不提供堆快照/性能追踪，无法准确报告 JS 堆内存 MB、证明不存在泄漏或给出 Core Web Vitals 分数。
