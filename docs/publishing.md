# 网页维护与发布

## 当前玩家界面

默认米白浅色，顶栏可切换深色。筛选栏提供网格、已完成、分 P、区域、搜索和地图选项；区域标题开关在设置中。地图名称为主世界／上方／下方／序章；区域标题默认关闭，已完成默认显示。窄屏优先保留地图选项文字，区域与搜索自适应收缩。

右侧时间轴首次默认收起；鼠标移到右侧中间显示展开图标，点击展开，再在相同位置收起。支持键盘聚焦，触屏直接显示。展开／收起及侧栏宽度记在本机，可拖拽边界调整宽度。展开不会改变区域筛选。

点击入口查看参考图、开始时间和原地图链接；「问题反馈」与首个视频时间同行。双击区域空白处切到单区域；点击入口和拖动不会切区。「完整地图」清除当前世界的分 P、区域、搜索条件，保留完成关卡显示开关。

## 完成状态和标记

展开关卡弹窗中的「关卡标记」，同一行提供大星星、多存档关、已完成关卡。已完成的标点、箭头和编号默认不透明度为 35%，设置可调整至 10%–100%；关闭顶栏「已完成」后隐藏这些入口及时间轴对应记录。取消完成需先开启顶栏显示，再点入口取消勾选。同一关卡 ID 的多个入口、四阶段／多次视频访问共享完成状态。

完成状态只表示玩家确认已完成，不表示其他关卡目前可达。进度保存在本机 `ootss.editorial.v3` 的 `levels[id].completed`，导入／导出名称与标注时一并保存。旧备份未包含 completed 时不会覆盖已有进度；显式 false 可取消完成。「重置所有更改」现在会清除全部手动、存档完成状态并解绑。

**不要把玩家导出的 completed 合并到公共 data/annotations.json。** 公共默认标记和个人进度应分开维护。

大星星初值来自 Joric Level_Entry 的 Hero 样式；多存档只支持手工勾选。备注、区域名及标签样式保存在本机，可导入导出。自定义文字已下线：不创建、不渲染、不编辑旧文字；旧 v3 文字只保留为兼容备份。

## 可选的区域和标签微调

分 P／单区域视图点击侧栏 ✎，或双击区域标题，可微调区域名、编号位置、字号和标点大小。点击区域名可原位改名；选中编号后在侧栏编辑位置，或拖动编号。Del 隐藏编号但保留入口；点击入口可恢复编号。Ctrl+Z 撤销，Ctrl+Shift+Z 重做，刷新后历史清空。

「恢复默认」只恢复全局样式；「重置所有更改」需弹窗确认，恢复全局／区域样式、标签位置和显示状态，清除所有完成状态并解绑，保留名称、星星／多存档标记和备注。区域名称可批量修改。

区域标题自动避让只在单分 P 或单区域且开启「位置适应」时运行。仅原图同格的不同关卡错开标点并用箭头指向真实位置，不调整单纯距离较近的入口。

## 视频序号与章节

源分 P 由 results/series/manifest.json 的 CID 固定。当前合集插入 P2 导览，因此源 P2 及之后显示为原序号加一。以后按 CID 更新映射，不能直接重编号审核数据：

```powershell
uv run python scripts/update_video_links.py
.\ootss.ps1 atlas --all-worlds
```

end1 在源 P24（当前 P25）为同一关卡的四阶段：01:03、05:59、10:54、15:46。results/p24/reviewed.json 保存用户确认的章节，旧五段在 superseded_events 中追溯。章节共享关卡序号，不列入可疑重复入口。

## 数据更新与发布

```powershell
.\ootss.ps1 atlas --all-worlds
uv run python scripts/audit_differences.py
python scripts/package_site.py
```

校对后同步重建对应分 P 导出与综合地图。results/stage1 保留为历史快照，正式网页发布 results/worlds。图像版本由 data/map_assets.json 固定；关卡目录身份版本独立保留。见 [底图更新记录](map-update-2026-10-26.md)。

master 的发布产物变化会触发 GitHub Pages。打包只含首页、网页脚本／样式、数据、CSV、审校网页与公开 assets，不含视频、缓存、本机配置或管理面板源码。备用站 https://jimmyzzt.github.io/OotSS_Sand/ ，正式站 https://sand.zzt.si/ 使用 Workers Static Assets。普通网页修改在 Pages 自动发布后，还需运行 npm run worker:deploy 更新正式域名的静态资源。详见 [静态托管与额度](hosting.md)。

Worker 修改后运行 npm run test:worker、npm run worker:check、npm run worker:deploy。不要写入凭证。反馈使用专用 D1，管理页与 API 均受 Access JWT 保护，见 [反馈说明](feedback.md)。

发布前运行 pytest、Ruff、Node 测试及脚本语法检查，并验收桌面／手机、完成状态保存与筛选、时间轴、弹窗和反馈入口。更多历史文档见 [归档](archive/README.md)。

顶栏新增绿色「读取游戏存档」和绑定后显示的浅红色「解绑存档」，只读取通关状态并保存本机快照。版本、冲突优先级、备份和解绑说明见 [读取存档](save-reading.md)。

普通打开首页恢复 `ootss.last-map.v1` 保存的地图；URL 中有效 map、level、p 参数优先。序章有独立投影，切换时同时更新瓦片边界。补充入口来源和视频对应见 [序章专项校对](../results/upstream/INTRO.md)。
