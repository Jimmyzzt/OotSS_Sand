# 发布与录制索引

公开仓库：[Jimmyzzt/OotSS_Sand](https://github.com/Jimmyzzt/OotSS_Sand)。GitHub Pages是源站；Cloudflare Worker在[sand.zzt.si](https://sand.zzt.si/)代理网页、页面资源和高倍率Joric底图。基础瓦片与参考缩略图随网站保存。Worker只允许GET/HEAD，目标固定，不转发访客Cookie或Authorization，无需为GitHub Actions配置Cloudflare凭证。

## 区域与关卡顺序

网格来自原Joric页面的gridLayer：宽19、高13，中心(80,69)，中心格边界X70.5–89.5/Y62.5–75.5；严格按原坐标定位，各物理地图分别保留有视频访问的区域（原一阶段快照85个）。P5的镜之群岛1–6分别是东1、东2、北1东2、北1东1、南1东3、南1东2，与用户参考图一致。区域名和涉及的分P默认作为一个整体放在左下；在单分P或单区域视图且开启“位置适应”时，遇到关卡标点/编号遮挡，依次尝试左上、右上、右下、中上、中下、左中、右中、中中，均被遮挡则回到左下；全局与单区域都可指定首选位置。放大后标点旁显示关卡序号。网格线独立开关，选定分P时只画其涉及区域的加粗边框，隐藏其他网格线；黄色选中框在独立上层，不会被相邻红框遮挡；区域标签、关卡标签也可分别关闭。

关卡编号按每个源分P中不同level_id首次出现的时间排列；重复访问不增加编号。P5有30段访问、27个不同关卡，编号1–27。区域路线保留返回：P5先经1、2、3、4，再返回3，之后5、6。地图右上左右箭头顺序前进，返回区域也不会形成导航死循环。选定分P时显示整P列表，选定区域时进一步筛选本区域。

中文主题名根据视频路线及原图area归纳，不视为游戏官方逐格命名。少数作者标题的方位叫法与坐标网格不完全一致（如P7标题南2/南4，而入口数据落在本网格南3/南5），保留题名并按原图坐标画格，不移动入口。data/annotations.json可增加regions字典，以地图ID:网格ID（如sky:1,0）为键，用title覆盖展示名。

录制时先选择分P，打开“网格”看整体路线，再进入区域，点“演示模式”隐藏顶栏。左右键切换区域，Esc退出。右栏保留关卡编号与谜题开始时间。也可用?p=5&record=1进入P5演示模式。当前交付是可用于录屏的页面，没有生成或上传索引视频。

## 主题与手动标注

默认米白浅色，右上可切换柔和深色。“设置”为下拉菜单，可调整标点0.6–2.6倍（默认1.6倍）、区域标签与关卡标签分别10–42px，并可选择各自的九宫格位置、关卡文字水平/垂直偏移（0–80px，默认右上5/4px）。标点随地图缩放，并为总览和近景保留尺寸上下限；白边突出入口，多存档关使用方形。设置保存在本机浏览器。

右侧栏提供列表和紧凑视图，默认紧凑，多列按攻略时间先后显示关卡序号和时间，包括同关卡的再次访问。桌面可拖动左侧分隔条在240–640px内调宽（不超过窗口60%），也可用分隔条的左右键调宽、Home/End切到边界。可收起或展开侧栏。页面固定于视口，关卡内容统一在侧栏内部滚动，滚动条使用透明轨道。

全部分P模式中，每个关卡标签都显示分P号，并按分P着色。数字序号固定在原本的位置，“2·”这类前缀绝对定位在数字左侧，不挤动“8”等关卡序号。选定分P后仅显示关卡序号。

在单区域/分P视图下点侧栏标题旁的✎，或双击区域标签，可进入“区域微调”。单击其他区域会退出微调并切换；双击其他区域则切换并进入该区域微调。微调时点击当前区域名称，直接在地图上改名，Enter保存、Esc取消；批量名称入口仍保留。

不再默认展开“当前关卡标签”或新建文字表单。只有选中编号、入口标点或自定义文字后，侧栏顶部才显示有明显边界的“当前编辑元素”区。可调整编号方位、横纵微调（±200px），或拖动地图上的编号；入口标点和原坐标不移动。Del隐藏选中的关卡标签，点击入口标点后勾选“显示此关卡标签”恢复。Del删除选中的自定义文本。

微调中双击当前区域空白处，选择“✎ 添加文本”，在点击位置创建可直接输入的文本框。初始字号等于区域标签字号；之后修改的文字样式会在当前页面内复用，刷新后新文本恢复以区域字号为默认。已有文字可拖动、原位编辑或在侧栏调整字号（10–72px）、颜色、描边（0–8px）及描边颜色。有自定义文字时，设置中提供“自定义文本”显示开关。

编辑历史最多缓存60步，Ctrl+Z撤销、Ctrl+Shift+Z或↷重做；连续输入合并，刷新即清空，历史不导出。输入框/原位文字中保留浏览器本身的文字撤销。全局样式在设置中调整；区域默认勾选“使用全局样式”，取消后将当前样式复制为本区域独立设置。“恢复默认”只恢复全局样式，不覆盖自定义区域、单关微调或已有自定义文本。“重置所有更改”需网页内弹窗确认：恢复全局/区域样式、标签位置和显示状态、文字字体颜色描边，保留名称、文字内容及坐标、星星/多存档标记和备注，可在本次页面撤销。

全部分P且未筛选区域时不运行自动避让；“区域标签”右侧的“位置适应”可进一步关闭。高倍率时关卡弹窗按需生成，不为总览中的每个点预建弹窗。设置不再重复提供主题选择，仅保留顶栏深浅色切换。

设置保留名称与标注的导入、导出入口。JSON仍为version=3：levels保留标注、单关位置和labelHidden；regions保留title、labelPosition、可选独立style和texts；style保存全局阅读设置和显示开关。兼容version=1/2及此前v3文件，旧本机设置自动延续。所有实际编辑即时保存在本机，历史与新文本默认样式的记忆仅在本次页面存在。

关卡弹窗将区域名放在标题右上，参考图右下提供原地图链接；只保留开始时间跳转，不显示时间范围和精度。展开默认折叠的“关卡标记”可勾选多存档关、调整大星星及写备注。大星星初值来自原始Level_Entry的Hero样式；多存档不做自动识别。标注只在当前浏览器保存。“导出手动标注”下载annotations.json，其他浏览器可导入；维护者将文件合并到data/annotations.json，运行uv run python -m ootss atlas --all-worlds并提交，即可更新共享站点。共享标注与本机覆盖值分开。

## 分P插入后的更新

results/series/manifest.json保存原CID和源分P，不要用新合集顺序覆盖它。运行：

```powershell
uv run python scripts/update_video_links.py
uv run python -m ootss atlas --all-worlds
```

脚本读取当前合集，用不可变CID找到原视频的新分P，写入data/video_links.json。丢失原CID会报错，不猜偏移。地图、区域顺序与关卡编号保持源记录不变；分P显示和跳转统一使用映射。当前尚未插入索引视频，映射为空，原链接不变。

## 部署

master上的results/worlds或results/stage1变化触发Publish atlas工作流。scripts/package_site.py默认发布results/worlds，只打包首页、脚本样式、JSON/CSV和assets；原视频、缓存、原帧及本机配置不进入Pages。源站为https://jimmyzzt.github.io/OotSS_Sand/。

Worker配置在wrangler.jsonc，账户和sand.zzt.si已核对。修改Worker后先npm run test:worker、npm run worker:check，再npm run worker:deploy；使用本机Wrangler登录，不写入凭证。普通网页更新只需Pages发布，无需重新部署Worker。

验证包括Python测试、Worker代理测试、标签分组及缩放的Node测试、Ruff、Node语法检查，以及桌面/窄屏布局、透明滚动条、标签开关、拖拽侧栏、手动标注与在线发布的浏览器核验。

筛选栏选择“主世界 / 天空世界 / 地下世界”；可使用 `?map=sky&p=25`、`?map=underworld&p=45` 深链接。后续阶段回访主世界不会被阶段筛选排除。区域改名以地图ID隔离，同坐标网格不会互相覆盖；导入导出一次包含三地图的本机修改。Worker仅代理三个白名单地图瓦片路径。

世界选择位于下方筛选栏“适应范围”左侧。“完整地图”会清除当前分P、区域、搜索条件和关卡定位，显示当前世界的全部已收录关卡，并同步移除链接中的分P参数。

重要校对结果在audit.html，设置的数据与来源中提供“校对清单”。每次修改审核身份后运行 `python scripts/audit_differences.py`，再打包发布。P68隐藏内容已从地图构建范围排除；原始下载和证据仍在工作资料中留存。

品牌旁“塞德莎攻略索引”链接到作者B站主页（UID 2940424，来自本地视频元数据）；深浅色按钮右侧提供GitHub仓库链接。紧凑列表的时间戳在各自剩余列宽内居中。

浏览器标签使用与品牌相同的金色四芒星SVG图标；顶栏顺序为深浅色、演示模式、设置、GitHub。地图右下仅保留Leaflet / Map: Joric，完整许可证仍在数据与来源中。“数据与来源”右侧的“进度查询”是友情链接，指向 https://sinkingstar.xpaw.me/，与本站本机标注互不共享数据。
